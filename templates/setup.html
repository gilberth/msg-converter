Bienvenido al wizard de configuración

Este wizard te ayudará a configurar la autenticación con Authentik de forma automática.

Lo que necesitas:
  • URL de tu instancia de Authentik
  • Token de API de Authentik (con permisos 'view' y 'write')
  • URL de esta aplicación
Lo que hará automáticamente:
  • Crear Provider OAuth2 en Authentik
  • Crear Application en Authentik
  • Generar credenciales (Client ID y Secret)
  • Configurar las variables de entorno
Importante: Necesitas crear un token de API en Authentik antes de continuar.
Ve a Directory → Tokens y crea uno con scopes 'view' y 'write'.
